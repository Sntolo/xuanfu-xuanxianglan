悬浮选项栏
=====

只显示**最新一条 AI 回复**里的剧情分支选项栏。楼层里那些重复的旧选项块全部隐藏，最新那份搬进一个可以拖动、可以收起的悬浮窗。

不修改正则，不修改聊天消息。正则照常渲染，脚本只负责“藏旧楼、取最新、自己画一份”。

## 安装

两种方式任选一种。

**导入 JSON**：打开酒馆助手的脚本库，用导入功能选 `悬浮选项栏.json`。

**粘贴代码**：在脚本库新建一个脚本，把 `悬浮选项栏.js` 的全部内容粘进去，保存并启用。

装好后刷新一次酒馆页面。页面右上角会出现选项悬浮窗；没有可选项时不显示。

## 用起来是什么样

- 面板默认停在右上角，拖标题栏可以挪位置，位置会记住。
- 点右上角那条横线，面板收起成一个悬浮球；点球重新展开。
- 悬浮球松手后自动吸附到离它最近的屏幕边（左或右），只留一半在屏内，呈半圆贴着屏幕边缘。
- 点选项正文＝直接发送该选项并触发 AI 回复。
- 点选项右侧的笔＝把该选项填进输入框，可以改完再发。
- 最新一条 AI 回复没带选项时，悬浮窗保持上一份内容，不闪也不空。

## 改配置

用记事本打开 `悬浮选项栏.js`，最上面有一段 `配置`：

| 项       | 作用                                                   |
| ------- | ---------------------------------------------------- |
| `标题`    | 面板顶部显示的文字                                            |
| `宽度`    | 面板宽度，窄屏会自动收窄                                         |
| `默认位置`  | 第一次出现时距右边、距上边多少像素                                    |
| `来源`    | 要收进悬浮窗的块。`特征` 是识别用的字符串，`提取` 是从消息原文里取内容的正则            |
| `球露出比例` | 悬浮球吸边后露在屏内的比例。默认 `0.5` 正好半圆；调大露得多，调小藏得多，有效范围 0.1～0.9 |

换一张卡，或者正则的样式改了，通常只需要改 `特征`：把它换成新正则里那个最外层容器独有的 class 名（例如 `npp-host-container`）。

`来源` 可以写多条。写两条以上时，面板顶部会出现标签，点标签切换不同的块。

## 手机端

- 收起按钮在触屏设备上常驻显示，点击区 32px；悬浮球 48px。不用先悬停再点。
- 悬浮球吸边后有一半在屏幕外，这是有意的半圆效果；露出的那一半可点。球里的图标会往屏内偏一点，不会被边缘裁掉。
- 竖直高度保留你松手的位置，只保证整颗球上下不出界。转屏后高度会重新夹紧，不会被顶到屏幕外。
- 保存的位置如果来自更大的屏幕（例如在电脑上拖到右下角），手机上打开时会自动吸附到最近的边，不会被藏到屏幕外。
- 手机转屏、地址栏收起、软键盘弹出后，面板会重新夹回屏内，悬浮球会重新贴回原来那一边。
- 校正只改显示位置，不会把手机上的坐标写回脚本变量，桌面和手机的位置互不覆盖。

## 已知限制

- 已在实机酒馆（127.0.0.1:9000）用手机视口跑过：吸附、点半圆展开、转屏保持，16 项全过。桩页面回归覆盖桌面 18 项、手机 21 项、吸附专项 23 项，全过。
- 楼层里的块是酒馆助手渲染的 iframe。脚本优先按 iframe 内容识别；读不到内容时，退一步按消息原文判断，只藏该楼层最后一个界面块。
- 脚本被关掉或页面刷新后，楼层的隐藏会自动恢复，不会留下空白。
- 软键盘弹起时如果视口变矮，面板会被往上推；键盘收起后自动回到原位置。这个过程中位置不会写回存储。

## 重新编译

源码在 `src/通用插件/悬浮选项栏/index.ts`。改完后执行：

```
node node_modules/typescript/bin/tsc -p tsconfig.fc.json
```

产物在 `_tmp/fc_build/src/通用插件/悬浮选项栏/index.js`，把它复制成 `悬浮选项栏.js` 即可。

```
node 验收/悬浮选项栏/桌面回归.mjs
node 验收/悬浮选项栏/手机验收.mjs
node 验收/悬浮选项栏/吸附验收.mjs

```

前三个跑通过/失败判定，最后一个只打印各场景的实测位置数据。
